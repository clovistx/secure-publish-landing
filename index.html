The problem

AI generates dashboards.
Sharing still leaks.

Models spit out dashboards, static sites, and analyses every day. Teams still drop them into Drive, Notion, or a public URL — and the share path becomes the leak.

Drive & Notion sprawl

HTML dashboards become attachments or weak previews. Permissions drift. Reviewers can’t tell what’s current or who can open it.

Public links leak

Anyone with the link can view the dashboard. A Slack forward is enough — the URL alone is the leak.

AI dashboards need company login

Access or VPN covers internal apps. Here the job is publishing the HTML your AI just made — as a signed-in-only page, not a loose file.

How it works

Install the skill.
Your agent handles the rest.

Prefer agents? Install Secure Publish once — the skill publishes the dashboard and keeps it behind company SSO. You don’t have to babysit the share path.

01

Install the skill

Add the Secure Publish skill to your agent environment. One install; it knows how to publish and share behind SSO.

Install example

$ npx skills add https://github.com/clovistx/secure-publish --skill "secure-publish"

Then tell your agent:

“Publish this HTML dashboard with Secure Publish.”

02

Ask your agent to publish

Point it at the AI-generated dashboard HTML. The skill ships it — no loose public file for visitors who aren’t signed in.

03

Teammates open with company login

Share the URL. Signed-in teammates see the dashboard; everyone else hits company login — not an open file.
